## 一句话（费曼版）
一家"卖算力使用量"的公司准备上市——它不卖芯片、不只卖模型，而是把大模型调用做成按量计费的生意。

## 它怎么运作（机制层）
- 上游：采购/租赁 GPU 算力 → 中游：做推理优化（同样的卡服务更多请求）→ 下游：按 token 卖 API
- "Token 工厂"= 把算力加工成 token 出售；赚钱的关键是 token 定价与算力成本之间的差价

## 为什么现在值得注意
- 如果上市成功，"模型推理"这个商业模式将第一次接受公开市场的检验
- 中国 AI 的叙事可能从"模型多强"转向"算力效率和现金流"

## 相反的观点（必须看）
- 各家都在打推理价格战，token 单价持续下降，毛利能守住吗？
- "第一股"不等于好生意：一级市场估值和二级市场定价可能分歧巨大
